<div aligh=left>
<h2>Requisitos</h2>
</div>

Antes de comenzar, asegúrate de tener instalado:

- Git
- Node.js (versión LTS)

Verificar instalación:

```bash
node -v
npm -v
git --version
```

---

<div aligh=left>
<h2>Clonar el repositorio</h2>
</div>

```bash
git clone https://github.com/EmirPolito/empresa-web
```

Entrar a la carpeta:

```bash
cd empresa-web
```

---

<div aligh=left>
<h2>Instalar dependencias</h2>
</div>

```bash
npm install
```

---

<div aligh=left>
<h2>Ejecutar TailwindCSS</h2>
</div>

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
npx @tailwindcss/cli -i ./css/input.css -o ./css/output.css --watch
```

Este comando debe permanecer ejecutándose mientras se desarrolla el proyecto.

---

<div aligh=left>
<h2>Ejecutar el proyecto</h2>
</div>

- Abrir el archivo `home.html` utilizando Live Server o cualquier servidor local.
- Se recomienda la extensión **Live Server** de Visual Studio Code.

---

<div aligh=left>
<h2>Reglas del proyecto</h2>
</div>

- No trabajar directamente sobre `main`.
- Cada integrante trabajará únicamente en su rama.
- Realizar commits frecuentes y con mensajes descriptivos.
- Antes de realizar un Pull Request verificar que todo funcione correctamente.
- Resolver conflictos antes de integrar cambios.
